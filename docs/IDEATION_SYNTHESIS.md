### Verdict: **Qvault Guardian** 🏆

**Why Guardian over SeedVault:**
1. **Integration Depth is 40% of the grade.** Guardian uses 4 features vs 3. That's a 20% scoring advantage on the single largest judging criterion.
2. **Triple convergence** — when all three AI models independently pick the same archetype as #1, the signal-to-noise ratio is deafening.
3. **Demo is more dramatic** — "catching a drainer live" beats "spell-checking seed words."
4. **Tether alignment** — Guardian is a product Tether would want in their ecosystem. SeedVault is a personal utility.
5. **SeedVault's weakness** — a BIP-39 validator is technically a dictionary lookup. Judges might score Technical Execution lower because the LLM isn't doing heavy reasoning.

**SeedVault stays as the fallback** — if QVAC's RAG pipeline proves too complex on Day 1, pivot to SeedVault immediately. It can be built in 1.5 days.

## 🏆 CHAMPION: Qvault Guardian

### One-Line Pitch
> Air-gapped AI wallet companion that scans transactions, verifies counterparties against a local threat database, and explains smart contract intent — all offline, zero key exposure.

### "Why Local?" Kill Shot
> You cannot send a pending transaction to a cloud AI without exposing your wallet address, your counterparty, your balance, and your trading intent. A cloud API is a front-running vector. Qvault Guardian runs 100% on-device. Zero bytes out.

### QVAC Feature Map (4 Features — 🔵 Full-Stack)

| Feature | Usage |
|---|---|
| **OCR** | Extract addresses & function signatures from screenshots, QR codes, transaction images |
| **RAG** | Local threat DB — known scam addresses, phishing contracts, drainer patterns |
| **LLM** | Analyze transaction intent, explain smart contract functions in human language, synthesize risk assessment |
| **STT** | Hands-free "Is this safe?" queries, voice-activated analysis |

### Risk Mitigations

| Risk | Mitigation |
|---|---|
| Shallow threat DB | Frame as "personal denylist with manual imports" — protocol, not a complete scanner |
| OCR accuracy on low-res screenshots | Pre-test with 5 sample images; hardcode fallback to clipboard paste |
| RAG retrieval quality | Use simple keyword + embedding hybrid; threat DB is small enough for exact match |
| LLM hallucination on contract analysis | Constrain prompt: "Only analyze based on RAG context. If no match, say 'Unknown.'" |
| Vulkan VRAM limits | Run models sequentially, not simultaneously; test on Day 1 |

### Secret Sauce

1. **"Zero Bytes Out" Widget** — Real-time network monitor in the UI footer showing 0 bytes transmitted. Every other crypto AI tool leaks your data. This one doesn't.
2. **Local Encrypted Audit Trail** — All analysis stored in encrypted SQLite. User can later prove due diligence without revealing addresses.
3. **Privacy Comparison Split-Screen** — Show what data a cloud AI would receive vs. what leaves your device (nothing). Powerful visual.
