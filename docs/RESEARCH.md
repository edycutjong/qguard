## Mission
Build with **QVAC** — Tether's local-first, hardware-agnostic AI inference engine. QVAC runs LLMs, RAG, speech-to-text, OCR, and translation entirely on-device using Vulkan compute. Zero cloud dependency.

## Track Scope & Focus Areas
- **Local LLM Inference** — run language models on consumer hardware via Vulkan
- **RAG (Retrieval Augmented Generation)** — local document Q&A without cloud
- **Speech-to-Text** — on-device transcription
- **OCR** — on-device document/image text extraction
- **Translation** — local language translation
- **Offline-First** — applications that work without internet

## SDK / Integration Primitives
- QVAC SDK — Vulkan-based AI inference engine
- Local LLM runtime (model loading, prompt, generate)
- RAG pipeline (embed, index, retrieve, generate)
- Whisper-compatible STT (speech-to-text)
- OCR engine (image/document text extraction)
- Translation engine (multi-language)
- All running on local hardware — no cloud APIs

## Submission Requirements

- Demo video showing local inference
- Must demonstrate meaningful QVAC integration
